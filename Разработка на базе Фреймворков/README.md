# Система бронирования переговорных комнат

## Назначение
Приложение для управления бронированием переговорных комнат в офисе. Позволяет сотрудникам проверять доступность помещений, создавать и отменять бронирования, избегая конфликтов и двойного бронирования.

## Целевая аудитория
- Сотрудники офиса, которым нужно забронировать переговорную для встречи
- Администраторы офиса, управляющие ресурсами переговорных комнат
- Руководители отделов, планирующие совещания

## Предметная область
Система работает в контексте офисного пространства, где есть несколько переговорных комнат разной вместимости и оснащения. Сотрудники могут бронировать комнаты на определенное время для проведения встреч, презентаций и совещаний. Система должна учитывать занятость комнат, их характеристики и предотвращать конфликты бронирований.

## Основные сущности
- Переговорная комната (номер, название, вместимость, наличие оборудования)
- Бронирование (дата, время начала, время окончания, статус)
- Сотрудник (ФИО, отдел, email)
- Оборудование (проектор, доска, кафедра)

## Основные функции
- Проверка доступности переговорной комнаты на указанную дату и время
- Создание нового бронирования с проверкой конфликтов
- Просмотр списка активных бронирований для выбранной комнаты
- Отмена существующего бронирования
- Получение информации о характеристиках переговорной комнаты

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django с интерфейсом для бронирования
- подключение базы данных для хранения информации о комнатах и бронированиях
- реализация системы пользователей с регистрацией и аутентификацией
- разработка REST API для интеграции с другими системами
- контейнеризация приложения в Docker
- настройка CI/CD для автоматического тестирования и деплоя
