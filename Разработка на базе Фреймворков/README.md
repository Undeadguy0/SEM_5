# Система бронирования переговорных комнат

Консольное приложение для учёта переговорных комнат офиса и управления их бронированием.

## Возможности
- просмотр и поиск переговорных по названию, вместимости, оборудованию;
- проверка доступности на временной слот;
- создание и отмена бронирований;
- просмотр расписания переговорной на дату;
- поиск бронирований по организатору.

## Структура проекта
- main.py — точка запуска, меню;
- rooms.py — работа с переговорными;
- bookings.py — работа с бронированиями;
- storage.py — сохранение/загрузка JSON;
- utils.py — вспомогательные функции ввода;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Требования
- Python 3.10+
- pytest
- flake8

## Установка зависимостей
pip install -r requirements.txt

## Запуск программы
python main.py

## Запуск тестов
pytest

## Проверка качества кода
flake8
